# Abhishek & Kanika — Wedding Invitation (#KaniKaAbhi)

Static site, ready for GitHub Pages. No build step.

## Deploy
1. Create a new public repo on GitHub (e.g. `kanika-abhishek-wedding`).
2. The site lives in `docs/` (including `.nojekyll`).
3. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch `main`, folder `/docs` → Save.
4. After ~1 minute the site is live at `https://<your-username>.github.io/<repo-name>/`.

## Personalised links
Add `?to=Name` to greet a guest by name on the envelope and pre-fill their WhatsApp RSVP:
`https://<your-username>.github.io/<repo-name>/?to=Sharma%20Family`
